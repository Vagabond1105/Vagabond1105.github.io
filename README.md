# Vagabond1105.github.io

Portfolio for Davlatsho Shirinbekov.

## Deploy
1. Create a public repo named `Vagabond1105.github.io`.
2. Upload everything in this folder (`index.html`, `assets/`, `.nojekyll`).
3. Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
4. The site goes live at https://vagabond1105.github.io

## Your photos
Your two portrait photos are (4:5 works best) in `assets/` with these names:
- `assets/me-profile.jpg` (page 1, the dossier)
- `assets/me-thobe.jpg` (page 5, behind the language subtitles on the CRT TV)

The profile photo is shown as a dithered dossier scan (hover or tap shows the original); the page 5 photo plays on the CRT TV.
Background video: drop `assets/wallpaper.mp4` (and optionally `assets/wallpaper.webm`) in and it replaces the animated wave automatically.
